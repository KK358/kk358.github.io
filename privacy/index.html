プライバシーポリシー

レイのAI競馬研究ノート 動画投稿ツール／最終更新 2026年9月16日

1. このツールについて

本ツールは、作成者が自分のYouTubeチャンネルへ動画を投稿するために作った 個人用のツールです。一般に配布・提供しているサービスではなく、 利用者は作成者本人のみです。

2. 取得する情報

本ツールが扱うのは、次の1点だけです。

  • YouTubeへの動画アップロード権限（OAuthトークン） — 作成者本人のGoogleアカウントについてのもの

氏名・メールアドレス・連絡先・視聴履歴・その他の個人情報は 一切取得しません。他の方の情報を取得することもありません。

3. 求める権限の範囲

  • 求める権限: youtube.upload（動画のアップロードのみ）
  • 求めない権限: 動画・チャンネル情報の閲覧、動画の削除、Googleアカウントのその他の情報

4. 情報の保存場所

OAuthトークンは作成者の個人PC内にのみ保存し、 外部のサーバーへ送信・保管しません。バージョン管理（Git）にも含めていません。

5. 第三者への提供

いかなる第三者へも提供・販売・共有しません。 広告配信や分析のための外部サービスも利用していません。

6. 情報の利用目的

取得した権限は、作成者自身のYouTubeチャンネルへ動画をアップロードする目的のみに 使用します。他の目的には使用しません。

7. 権限の取り消し

付与した権限は Googleアカウントの権限設定 からいつでも取り消せます。取り消すと本ツールはアップロードできなくなります。

8. Google APIサービスの利用

本ツールによるGoogle APIから受け取った情報の利用は、 Google API Services User Data Policy （Limited Use requirements を含む）に準拠します。

9. 本ポリシーの変更

変更する場合は、このページに掲載し、最終更新日を改めます。

10. お問い合わせ

本ポリシーに関するお問い合わせは note のプロフィール からご連絡ください。
