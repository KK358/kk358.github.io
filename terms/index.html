利用規約

レイのAI競馬研究ノート 動画投稿ツール／最終更新 2026年9月16日

1. このツールの位置づけ

本ツールは、作成者が自分のYouTubeチャンネルへ動画を投稿するために作った 個人用のツールです。第三者へ提供・販売しているサービスではなく、 利用者は作成者本人のみです。

2. できること

本ツールは、作成者本人のGoogleアカウントの許可を得て、 作成者本人のYouTubeチャンネルへ動画をアップロードします。 それ以外の操作（動画の閲覧・削除、チャンネル設定の変更など）は行いません。

3. 禁止事項

本ツールを、次の目的で使用しません。

  • 他人のアカウントへの接続
  • YouTubeの利用規約および YouTube API サービス利用規約に反する行為
  • 自動化による過大な負荷をかける行為

4. 投稿内容について

本ツールが投稿する動画は、競馬のレース予想を扱った情報提供・研究目的の内容です。 予想の的中や利益を保証するものではありません。 馬券の購入はご自身の判断と責任で行ってください。

5. 免責

本ツールは現状有姿で提供され、動作の継続性・正確性について保証しません。 作成者は、本ツールの使用または使用不能から生じたいかなる損害についても責任を負いません。

6. 変更・終了

作成者は、予告なく本ツールの内容を変更し、または使用を終了することがあります。 本規約を変更する場合は、このページに掲載し、最終更新日を改めます。

7. 準拠法

本規約は日本法に準拠します。
